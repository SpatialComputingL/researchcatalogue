Lab model

Info

This 3D model is an interactive spatial reference for the Spatial Computing Lab. It shows the three fixed projection walls, the floor projection, the mobile fourth wall, the ceiling grid, the sixteen loudspeakers, the Azure Kinect sensors and the reference listening point, all in the room coordinate frame used by every lab component. It is meant to answer where is what? before a visit: to plan where zones and virtual objects go relative to the walls and the entrance, to understand the speaker layout behind Max-MSP ambisonic renderer, and to compare positions in TouchDesigner with the physical room.

Approximate elements are drawn faded and labelled approx. in the viewer. The subwoofer is not drawn: it radiates omnidirectionally and its position has no effect on decoding.

Coordinate frame

Metres. X = width (west −, east +), Y = height, Z = depth. The origin is on the floor at the middle of the north (centre) wall. Z increases towards the entrance (south). This is the same frame used by Azure Kinect sensors, Virtual objects and the sound system, so a position read in the viewer can be typed straight into a component.

Using the viewer

  • Views:
  • 3D overview
  • Floor plan: top-down, with north at the top
  • From entrance: what a visitor sees on entering
  • Listener: from the reference listening point, looking north
  • Layers: walls and floor, mobile wall, loudspeakers, sensors, ceiling grid, helpers and labels can each be switched on or off.
  • Details: click any object to see its coordinates. For speakers this includes azimuth, elevation and distance to the listening point.
  • Download .glb: exports the geometry as a standard glTF binary, for use in Blender, game engines or other 3D tools.
  • Add ?view=top (or entrance, listener) to the URL to open the viewer on a specific view.

Technical notes

  • One small file. The model is not a stored mesh. It is built in the browser from a short data block at the top of the HTML file, with three.js loaded from a CDN. The file is about 15 KB, so it hardly uses any of the website's storage. To update a position, edit the numbers in that data block. Nothing else needs to change.
  • Not a scan. The model is schematic. A photogrammetric or LiDAR scan of the room can be added later as a .glb and loaded into the same viewer.
